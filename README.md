# AlphaXER Launcher - Official Website

Modern, clean, ultra-fast landing website for **AlphaXER Launcher** (Minecraft 1.21.1 custom launcher).
Designed and crafted by **mayankmandrai**.

## Features
- **Modern Dark Blue Aesthetics**: `#0b1329` main background, `#1e293b` glass cards, vibrant `#3b82f6` glowing accents.
- **Top Search Engine Ranking (Google & Brave)**: Complete OpenGraph, Twitter Cards, Semantic Schema.org JSON-LD (`SoftwareApplication`, `WebSite`, `FAQPage`), sitemap.xml & robots.txt.
- **Dual Loader Showcase**: Interactive switch between Fabric 1.21.1 and NeoForge 21.1.65.
- **Direct Download Buttons**: One-click downloads for Windows NSIS Setup (`.exe`) and Portable Edition.
