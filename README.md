## Deploy to Vercel (1-Click)

### Step 1: Initialize Git and Push to GitHub (Private Repo)
Run these commands in this `alphaxer-website` folder:

```bash
git init
git add .
git commit -m "feat: Initial commit for AlphaXER Launcher official website"
git branch -M main
git remote add origin https://github.com/mayankmandrai/alphaxer-website.git
git push -u origin main
```

### Step 2: Import into Vercel
1. Go to [https://vercel.com/dashboard](https://vercel.com/dashboard).
2. Click **Add New Project** -> **Import Git Repository**.
3. Select your private `alphaxer-website` repository.
4. Framework Preset: **Other** (Root directory: `./`).
5. Click **Deploy**.

Your website will be live in less than 20 seconds at `https://alphaxer-launcher.vercel.app` (or your custom domain) with full SSL and edge CDN!
